# 모드 GUI 제약 사항

Minecraft 26.3 · Fabric 기준으로 모드 GUI를 만들 때 알아 둘 제약을 정리한 문서입니다.
수치는 26.3 클라이언트 코드에서 직접 확인한 값입니다. (2026-11-25 작성)

## 1. 화면 크기와 글자

**좌표는 실제 픽셀이 아니라 GUI 배율 단위입니다.** 설정의 GUI 크기(1~4, 자동)에 따라 쓸 수 있는 화면이 달라집니다.
예를 들어 1920×1080 모니터에서 배율 4면 480×270입니다. 큰 화면을 만들면 높은 배율에서 밖으로 넘칠 수 있으므로,
최소 크기 기준(예: 320×240 안에 들어가기)을 정하고 그 안에 맞춥니다. 창 크기가 바뀌면 `init()`이 다시 호출되므로
위치는 항상 화면 크기를 기준으로 계산합니다.

**글자 크기는 사실상 하나입니다.** 기본 폰트는 줄 높이 9px 비트맵 폰트이고, 크기를 바꾸려면 화면을 확대·축소해야 합니다.
정수 배율(2배, 3배)은 깔끔하지만 1.5배처럼 정수가 아니면 흐릿해집니다. 한글은 기본 폰트에 없어 영문과 모양이 다른 대체 폰트로 표시됩니다.
TTF 폰트를 모드에 넣어 바꿀 수 있지만 한글 폰트는 용량이 크고 라이선스를 확인해야 합니다.

## 2. 그릴 수 있는 모양

| 할 수 있는 것 | 직접은 어려운 것 |
|---|---|
| 가로·세로 사각형, 테두리 | 둥근 모서리, 원, 대각선 |
| 위→아래 그라데이션 | 좌→우, 원형 그라데이션 |
| 반투명 색 | 퍼지는 그림자 |
| 이미지(텍스처) | 벡터 아이콘 |

둥근 모서리나 아이콘이 필요하면 이미지 파일을 모드에 넣어서 그립니다. 9-slice(모서리는 유지하고 가운데만 늘리는 방식)를 쓰면
이미지 하나로 여러 크기의 패널을 만들 수 있습니다.

- **겹침 순서:** 같은 층에서는 글자가 항상 사각형 위에 그려집니다. 드롭다운·툴팁처럼 다른 내용 위에 상자를 띄우려면
  층을 나누어야 합니다(`GuiGraphicsExtractor.nextStratum()`).
- **배경 블러:** 렌더러가 "블러 전/후" 두 단계로만 나뉘어 있어 한 프레임에 한 번만 걸 수 있습니다.
  팝업은 블러 대신 반투명하게 어둡게 하는 방식을 씁니다(`QuakeTheme.OVERLAY`).
- **확대 애니메이션:** 화면을 확대·축소하는 동안 마우스 클릭 위치는 변환되지 않습니다. 짧은 열기 애니메이션 정도로만 씁니다.

## 3. 게임 플레이

**팝업(Screen)이 열려 있으면 플레이어가 움직일 수 없습니다.** 마우스 커서가 나타나고 이동 입력이 막힙니다.
그래서 화면을 두 종류로 나눕니다.

- **팝업(Screen):** 로비, 대기 중, 리스폰 대기처럼 안전할 때만 엽니다. 상점, 장비, 설정이 여기에 해당합니다.
- **HUD:** 게임 중에 상시 표시하며 클릭할 수 없고 보여 주기만 합니다. 체력, 탄약, 점수가 여기에 해당합니다.

**단축키 겹침:** 바닐라 키와 겹치면 따로 처리해야 합니다(테스트용 Ctrl+F는 F의 양손 교체 입력을 버리도록 처리).
정식 화면은 설정에서 바꿀 수 있는 키 바인딩으로 만듭니다.

## 4. 서버-모드 구조

- **응답 시간차:** 버튼을 누르면 서버에 요청을 보내고, 서버가 판정한 뒤 응답이 와야 결과를 알 수 있습니다.
  판정은 조작 방지를 위해 항상 서버가 합니다. 버튼에는 처리 중, 실패 상태를 표시합니다.
- **패킷 크기 제한:** 서버 → 클라 1,048,576바이트(1MB), 클라 → 서버 32,767바이트.
  이미지처럼 큰 데이터는 패킷으로 보내지 않고 모드나 리소스팩에 넣습니다.
- **모드 미설치 플레이어:** 모드를 선택 설치로 하면 모드 화면마다 Dialog나 상자 GUI로 된 대체 화면이 필요합니다.
  GUI를 본격적으로 만들기 전에 필수 여부를 정합니다.

## 5. 유지보수

Minecraft GUI 코드는 버전마다 자주 바뀝니다. 26.3에서도 `render` → `extractRenderState`,
`Minecraft.setScreen` → `Minecraft.gui.setScreen`처럼 이름과 위치가 바뀌었습니다.
그리는 코드는 `client/ui` 패키지(`PopupScreen`, `PopupButton`, `QuakeTheme`)에 모아 두고,
각 화면은 이 부품을 통해서만 그립니다. 버전을 올릴 때 `ui` 패키지만 고치면 되게 하기 위해서입니다.
